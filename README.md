# Living Space Design

Small-space apartment decor on a budget. Free site, built for GitHub Pages.

## Publish (when Huzaf says go)
1. Create repo `livingspacedesign.github.io` on GitHub account `livingspacedesign`.
2. Upload all files in this folder to that repo (index.html, style.css, the two article pages, README.md).
3. Enable GitHub Pages (Settings → Pages → Deploy from branch, main). Site: https://livingspacedesign.github.io

## Files
- `index.html` — homepage (Hero, Recently, Small Space 101, Featured This Season)
- `style.css` — original stylesheet
- `small-living-room-ko-bada-kaise-dikhayein.html` — Phase 1 article 1
- `small-bedroom-storage-ideas-under-100.html` — Phase 1 article 2
